Getting Started

Normaliz.jl is a Julia interface to Normaliz, an open source tool for computations in affine monoids, vector configurations, lattice polytopes, and rational cones.

Installation

To use Normaliz.jl we require Julia 1.10 or higher. Please see https://julialang.org/downloads/ for instructions on how to obtain julia for your system.

To install this package, enter this into the Julia prompt:

using Pkg; Pkg.develop(url="https://github.com/Normaliz/Normaliz.jl")

The C++ part of the package is compiled when it is first loaded, which requires a C++ compiler and cmake.

Basic usage

A Cone is constructed from matrices, passed as keyword arguments named after Normaliz input types, and its properties are retrieved with cone_property:

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5], grading = [1 1])
Normaliz cone

julia> cone_property(C, :HilbertBasis)
2×2 Matrix{BigInt}:
 1  2
 3  5

julia> cone_property(C, :EmbeddingDim)
2

Normaliz keeps computed properties with the cone, so asking for a property again does not recompute it. is_computed and computed_cone_properties tell which properties are available, and known_cone_properties lists all property names.

Computing properties together and choosing algorithms

compute! computes several properties in one Normaliz run, which lets Normaliz share work between them. The results are then retrieved with cone_property, without computing them again.

Both compute! and cone_property accept Normaliz flags as Bool keyword arguments named after the flag, for example DualMode = true to use the dual algorithm instead of the primal one:

julia> using Normaliz

julia> D = Cone(; cone = [1 0; 1 3], grading = [1 0]);

julia> compute!(D, :HilbertBasis, :SupportHyperplanes; DualMode = true);

julia> cone_property(D, :SupportHyperplanes)
2×2 Matrix{BigInt}:
 0   1
 3  -1

Any flag known to Normaliz can be passed this way; see the section "Computation goals and algorithmic variants" of the Normaliz manual. Since a computed property is never recomputed, flags only affect properties that have not been computed yet.

Public API

Cones and their properties

Normaliz.Cone — Type
Cone(input::AbstractDict; type::Symbol = :gmp)
Cone(; type::Symbol = :gmp, kwargs...)

Construct a Normaliz cone from Julia matrices.

Inputs use Normaliz input names as keyword arguments or as Symbol keys in a dictionary, for example :cone and :grading. Matrix entries must be convertible to rational numbers. By default, Normaliz uses arbitrary precision integer arithmetic; pass type = :longlong to use 64-bit integer arithmetic.

Examples

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5], grading = [1 1])
Normaliz cone

julia> cone_property(C, :HilbertBasis)
2×2 Matrix{BigInt}:
 1  2
 3  5

Normaliz.cone_property — Function
cone_property(cone::Cone, property::Union{AbstractString,Symbol}; flags...)

Return property of cone, computing it first if it has not been computed yet.

Property names are those listed by known_cone_properties. The result is converted to an ordinary Julia object: Matrix{BigInt}, Vector{BigInt}, BigInt, Rational{BigInt}, Float64, Int, or Bool, depending on the property. Properties with other kinds of results, such as Triangulation or HilbertSeries, are not yet supported and throw an ArgumentError.

flags are Bool keyword arguments, e.g. DualMode = true, exactly as for compute!.

Examples

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5], grading = [1 1]);

julia> cone_property(C, :HilbertBasis; DualMode = true)
2×2 Matrix{BigInt}:
 1  2
 3  5

julia> cone_property(C, :EmbeddingDim)
2

Normaliz.compute! — Function
compute!(cone::Cone, property, properties...; flags...) -> Cone

Compute one or more properties for cone in a single Normaliz run, and return cone. The results are not returned: retrieve them afterwards with cone_property, which does not compute them again. Normaliz throws an error if it cannot compute one of the properties, unless the flag DefaultMode = true is given, in which case it skips such properties (see is_computed).

Use compute! to compute several properties together, which lets Normaliz share work between them instead of requesting them one by one. To compute and retrieve a single property, call cone_property directly.

Property names are those listed by known_cone_properties. flags select how Normaliz computes them, given as Bool keyword arguments named after the Normaliz flag, e.g. DualMode = true to use the dual algorithm, or BigInt = true to compute with arbitrary precision integers. Flags set to false are ignored. Any flag known to Normaliz is accepted; see the section "Computation goals and algorithmic variants" of the Normaliz manual. Normaliz throws an error for unknown names and for contradictory flags, such as DualMode together with PrimalMode.

Normaliz never recomputes a property, so flags have no effect on properties that have already been computed (see is_computed).

Examples

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5], grading = [1 1]);

julia> compute!(C, :HilbertBasis, :Multiplicity; DualMode = true);

julia> cone_property(C, :Multiplicity)
1//24

Inspecting properties

Normaliz.is_computed — Function
is_computed(cone::Cone, property::Union{AbstractString,Symbol}) -> Bool

Return whether property has already been computed for cone.

Examples

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5]);

julia> is_computed(C, :ExtremeRays)
false

julia> cone_property(C, :ExtremeRays);

julia> is_computed(C, :ExtremeRays)
true

Normaliz.computed_cone_properties — Function
computed_cone_properties(cone::Cone) -> Vector{String}

Return the names of properties that have already been computed for cone.

Examples

julia> using Normaliz

julia> C = Cone(; cone = [1 2; 3 5]);

julia> "ExtremeRays" in computed_cone_properties(C)
false

julia> cone_property(C, :ExtremeRays);

julia> "ExtremeRays" in computed_cone_properties(C)
true

Normaliz.known_cone_properties — Function
known_cone_properties() -> Vector{String}

Return the names of cone properties known to Normaliz, i.e. the properties that can be computed with compute!.
